# Tabata Timer

Einstellbarer Intervall-Timer: Standard 40 s Arbeit, 20 s Pause, 8 Runden, 5 s Vorlauf.
Kurze Glocke zu Beginn und am Ende jeder Arbeitsphase. Ein Ring zeigt den Fortschritt über das ganze Workout.

Steuerung: Start, Pause/Weiter, Neu starten, Abbrechen. Tastatur: Leertaste = Start/Pause, Esc = Abbrechen.

Eine einzelne statische Datei (`index.html`), keine Abhängigkeiten.
